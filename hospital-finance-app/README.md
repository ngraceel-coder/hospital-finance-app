# 🏥 온소아청소년과의원 재정관리 웹앱

Notion을 백엔드로 사용하는 병원 재정관리 시스템입니다.

---

## 📋 주요 기능

- **대시보드**: 수입/지출 현황, 예상 지출 예측
- **거래내역**: 수입/지출 기록 (자동 분류 지원)
- **체크리스트**: 월별 업무 체크리스트 (추가/삭제 가능)
- **사진 업로드**: ⭐ **GPT-4o-mini OCR** - 은행 앱 캡처 사진을 저렴하게 인식 (사진당 1~4원)
- **설정**: 월별 예산 추가/수정/삭제 (다른 페이지에 자동 반영)
- **로그인**: 비밀번호 보호
- **Notion 연동**: 모든 데이터가 Notion에 저장됨

---

## 🚀 배포 방법 (따라하기)

### 1단계: Notion 설정

#### 1-1. Notion Integration 만들기

1. https://www.notion.so/my-integrations 접속
2. **"새 통합 만들기"** 클릭
3. 이름: `병원재정관리` (아무거나 OK)
4. **제출** 클릭
5. **"내부 통합 시크릿"** 복사해서 메모장에 저장 (나중에 필요!)

#### 1-2. Notion 데이터베이스 3개 만들기

Notion에서 새 페이지를 만들고, 아래 3개의 데이터베이스를 만드세요.

**① 거래내역 데이터베이스**
| 속성 이름 | 속성 타입 |
|---------|---------|
| 내용 | 제목 (기본) |
| 날짜 | 날짜 |
| 구분 | 선택 (옵션: 수입, 지출) |
| 금액 | 숫자 |
| 분류 | 선택 (옵션: 인건비, 임대료, 의약품 등) |

**② 체크리스트 데이터베이스**
| 속성 이름 | 속성 타입 |
|---------|---------|
| 항목 | 제목 (기본) |
| 카테고리 | 선택 (옵션: 세무/회계, 급여/인건비, 거래처, 임대료/관리비, 대출/금융, 기타) |
| 마감일 | 숫자 (1~31) |
| 적용월 | 다중 선택 (옵션: 1, 2, 3, ... 12) |
| 완료 | 체크박스 |
| 완료월 | 텍스트 |

**③ 설정(예산) 데이터베이스**
| 속성 이름 | 속성 타입 |
|---------|---------|
| 분류 | 제목 (기본) |
| 월예산 | 숫자 |

#### 1-3. Integration 연결하기

각 데이터베이스에서:
1. 오른쪽 상단 **...** 클릭
2. **"연결 추가"** 클릭
3. 아까 만든 **"병원재정관리"** 선택

#### 1-4. 데이터베이스 ID 복사하기

각 데이터베이스 페이지 URL에서 ID를 찾으세요:
```
https://www.notion.so/내워크스페이스/거래내역-abc123def456...
                                    ^^^^^^^^^^^^^^^^
                                    이 부분이 ID!
```

3개 데이터베이스의 ID를 각각 메모장에 저장하세요.

---

### 2단계: Vercel 배포

#### 2-1. GitHub에 코드 올리기

1. https://github.com 로그인
2. **New repository** 클릭
3. 이름: `hospital-finance-app`
4. **Create repository** 클릭
5. 이 폴더의 모든 파일을 업로드

#### 2-2. Vercel 연결하기

1. https://vercel.com 접속 (GitHub로 로그인)
2. **Add New Project** 클릭
3. 방금 만든 `hospital-finance-app` 선택
4. **Import** 클릭

#### 2-3. OpenAI API 키 발급 (OCR용)

1. https://platform.openai.com 접속
2. 로그인 또는 회원가입
3. 우측 상단 프로필 → **API Keys** 클릭
4. **Create new secret key** 클릭
5. 생성된 API 키 복사 (sk-로 시작)

**비용 안내**: 사진 1장당 약 $0.001~0.003 (한화 약 **1~4원**) - GPT-4o-mini 사용

#### 2-4. 환경 변수 설정

Deploy 전에 **Environment Variables** 섹션에서:

| 이름 | 값 |
|-----|-----|
| `NOTION_API_KEY` | 1단계에서 복사한 시크릿 |
| `NOTION_TRANSACTIONS_DB` | 거래내역 데이터베이스 ID |
| `NOTION_CHECKLIST_DB` | 체크리스트 데이터베이스 ID |
| `NOTION_SETTINGS_DB` | 설정 데이터베이스 ID |
| `OPENAI_API_KEY` | OpenAI API 키 (sk-로 시작) |
| `LOGIN_PASSWORD` | 원하는 비밀번호 (예: hospital2024!) |
| `JWT_SECRET` | 아무 긴 문자열 (예: mysupersecretkey123456789) |

#### 2-5. 배포!

**Deploy** 버튼 클릭하면 끝!

배포 완료 후 `https://your-app.vercel.app` 주소로 접속하세요.

## 💡 사용 팁

### 초기 데이터 입력

1. **설정 탭**에서 월별 예산을 먼저 입력하세요:
   - 인건비: 26,000,000
   - 임대료: 7,050,000
   - 4대보험: 4,500,000
   - 의약품: 12,000,000
   - 대출이자: 6,200,000
   - 관리비/청소: 3,000,000

2. **체크리스트 탭**에서 매달 해야 할 업무를 추가하세요

3. 거래가 발생할 때마다 **거래내역** 또는 **업로드**에서 추가하세요

### 자동 분류

거래 내용에 아래 키워드가 포함되면 자동으로 분류됩니다:
- 급여, 김진, 김다정 → **인건비**
- 지엔팜, 블루팜코리아 → **의약품**
- 녹십자의료재단 → **검사비**
- 국민연금, 건강보험 → **4대보험**
- 등등...

## ❓ 문제 해결

### "로그인이 안 돼요"
→ Vercel 환경 변수의 `LOGIN_PASSWORD`가 정확한지 확인

### "데이터가 안 불러와져요"
→ Notion 데이터베이스에 Integration이 연결되었는지 확인
→ 데이터베이스 ID가 정확한지 확인

### "거래 추가가 안 돼요"
→ Notion API 키가 유효한지 확인
→ 데이터베이스 속성 이름이 정확한지 확인
