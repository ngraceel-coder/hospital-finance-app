# 블로그 수익화 자동화 아키텍처 설계

> 목표: **주제 발굴 → 콘텐츠 생성 → 발행 → 수익화**를 사람 개입 최소화로 자동 운영

---

## 1. 채널 조사 결과 (왜 워드프레스인가)

각 채널을 "자동화 가능성 × 수익 단가 × 진입 난이도"로 평가했습니다.

| 채널 | 자동 발행 | 수익 수단 | 단가 | 자동화 적합성 | 결론 |
|------|-----------|-----------|------|---------------|------|
| **워드프레스** | ✅ REST API 완전 지원 | 애드센스 + 쿠팡 + 제휴 전부 | 높음(애드센스) | ★★★★★ | **채택** |
| 네이버 블로그 | ❌ 글쓰기 API 폐지(2020.5) | 애드포스트만 | 낮음 | ★☆☆☆☆ | 반자동(선택) |
| 티스토리 | △ API 불안정 | 애드센스 | 중 | ★★☆☆☆ | 보조 |
| 유튜브 | △ Data API로 업로드 가능 | 애드센스(영상) | 중~높음 | ★★★☆☆ | 확장 여지 |
| 브런치 | ❌ | 없음(외부 유입용) | - | ☆ | 제외 |

**핵심 제약**
- 네이버는 광고성 글 억제를 위해 **글쓰기 API를 폐지**했고, 브라우저 자동화는 약관 위반·계정 정지 위험. → 완전 무인 자동화 불가.
- **애드센스는 네이버 블로그에 부착 불가.** 고단가 수익을 노리면 워드프레스/티스토리가 필수.
- 따라서 "완전 자동화 + 고수익"의 유일한 정답은 **워드프레스 + 애드센스 + 쿠팡파트너스**.

> 유튜브는 같은 콘텐츠 파이프라인에 TTS+자막을 얹으면 확장 가능(로드맵 4단계).

```

│ keyword_research │──▶│  topic_selector  │──▶│ content_generator│

│ scheduler/       │   │  monetization    │   │ wordpress_       │

                         └─────────────────────────────────────┘
```

## 3. 모듈별 책임

| 모듈 | 입력 | 처리 | 출력 |
|------|------|------|------|
| `core/keyword_research.py` | 시드 키워드 | 네이버 API로 검색량·경쟁도 조회 → **수익성 점수** 계산 | 스코어링된 키워드 리스트 |
| `core/topic_selector.py` | 키워드 리스트 | Claude가 니치별 5개 후보 생성 → 지표로 3개 확정 | 확정 주제 + 글감 목록 |
| `core/content_generator.py` | 확정 주제/키워드 | Claude로 SEO 최적화 아티클 생성 | 제목/본문(HTML)/메타/태그 |
| `core/monetization.py` | 생성된 HTML | 애드센스 코드 + 쿠팡 링크 자동 삽입 | 수익화 완료 HTML |
| `core/wordpress_publisher.py` | 완성 글 | WP REST API로 발행(카테고리/태그/예약) | 발행 URL |
| `core/pipeline.py` | 니치 설정 | 위 전 단계를 순차 실행 | 발행 결과 리포트 |
| `scheduler/daily_run.py` | - | 매일 N개 글을 파이프라인으로 자동 생성·발행 | 로그 |

## 4. 수익화 스택

1. **구글 애드센스** — 본문 상/중/하단 자동 삽입. 고단가 니치(금융/보험)일수록 RPM↑
2. **쿠팡 파트너스** — 제품/건강 니치 글에 제휴 링크 자동 삽입 → 구매 전환 커미션
3. **(확장) 애드핏/데이블** — 국내 광고 네트워크 병행

### 수익 공식
```
월 수익 ≈ 월 방문자수 × 페이지뷰 × (애드센스 RPM/1000) + 제휴 전환수 × 평균커미션
```
- 신규 블로그는 **구글 샌드박스(3~6개월)** 동안 트래픽이 느림 → 이 기간에 글 자산을 쌓는 게 자동화의 목적.
- 전략: **정보성 롱테일 키워드**로 초기 노출 확보 → 축적된 도메인 신뢰도로 고단가 키워드 상위 노출.

## 5. 니치 3종 전략 (순수 수익 최적화)

| 블로그 | 역할 | 수익 수단 | 근거 |
|--------|------|-----------|------|
| **A. 정부지원금·정책자금 안내** | 트래픽 엔진 | 애드센스 | 검색량 폭발적, 이슈성 유입, 경쟁 상대적 완화 |
| **B. 보험·금융 롱테일 정보** | 수익 엔진 | 애드센스(최고 CPC) | 보험/대출 CPC 최상위, 롱테일로 신규 진입 가능 |
| **C. 건강·영양 + 제품추천** | 수익 다변화 | 애드센스 + 쿠팡 | 검색량 큼, 제휴 구매전환 이중 수익 |

> 세 주제는 서로 트래픽·수익·전환 성격이 달라 **리스크 분산**됨.
> 실제 최종 확정은 `keyword_research.py`가 네이버 실검색량으로 검증 후 결정.

## 6. 안전장치 & 품질 관리

- **DRY_RUN 모드**: 실제 발행 없이 로컬에 결과 저장(초기 검증용).
- **PUBLISH_STATUS=draft**: 초안으로 발행 → 사람이 검수 후 게시(초기 권장).
- **중복 방지**: 발행 이력(`data/output/published.json`)으로 같은 주제 재생성 차단.
- **품질 게이트**: 글자수/키워드 밀도/금지어 체크 후 발행.
- **YMYL 유의**: 금융·건강은 구글이 신뢰도(E-E-A-T)를 엄격 심사 → 출처/면책 문구 자동 삽입.

## 7. 로드맵 (확장)

1. **1단계(현재)**: 워드프레스 자동 발행 + 애드센스/쿠팡
2. **2단계**: 성과 분석(구글 애널리틱스/서치콘솔 API) → 잘 되는 키워드 재투자
3. **3단계**: 이미지 자동 생성(썸네일/일러스트), 내부 링크 자동 연결
4. **4단계**: 유튜브 확장(글→TTS→자막 영상 자동 업로드), 뉴스레터 연계
